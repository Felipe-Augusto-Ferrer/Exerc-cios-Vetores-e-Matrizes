📖 Sobre o repositório

Este repositório reúne uma série de exercícios em Python desenvolvidos para a disciplina de Raciocínio Algorítmico, com foco no uso de vetores (listas) e matrizes para resolver problemas lógicos e computacionais.

São 13 exercícios independentes, cada um explorando uma aplicação diferente dessas estruturas de dados — desde manipulações simples de listas até operações mais elaboradas com matrizes bidimensionais.

🧠 Conceitos aplicados
Criação e manipulação de vetores (listas)
Criação e manipulação de matrizes (listas de listas)
Percorrimento com laços de repetição (for, while)
Operações de busca, soma, ordenação e contagem em estruturas de dados
Validação de entrada do usuário
Lógica de programação aplicada a problemas estruturados
📁 Estrutura do repositório

Cada arquivo ExercicioN.py corresponde a um exercício individual, numerado de 1 a 13.
